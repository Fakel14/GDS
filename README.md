# GDS — Geometry Dash Songs

Демонстрационный маркетплейс музыки, ремиксов и скаутинга для сообщества Geometry Dash.

## Запуск на Windows

Установите Node.js LTS. В терминале в папке проекта выполните:

```bash
npm install
npm run dev
```

Откройте адрес Vite из терминала (обычно http://localhost:5173). Команда запускает и сайт, и сервер аккаунтов. Для остановки нажмите Ctrl+C. `npm run build` собирает сайт, а `npm start` запускает сервер с готовой сборкой на порту 3001.

## Заявка и аккаунт

1. Пользователь заполняет никнейм, профиль Newgrounds и контакт. Никнейм — от 3 до 30 букв, цифр, символов `_` или `-`.
2. Сайт подготавливает текст заявки. **Пользователь сам копирует и отправляет его в личные сообщения аккаунту fakelo4ik на Newgrounds.** Сайт не отправляет сообщения автоматически и не получает подтверждения доставки.
3. Администратор вручную проверяет профиль и наличие вайтлиста Geometry Dash. После одобрения он на сервере GDS, где запущен сайт, выполняет:

   ```bash
   npm run account:create -- "Никнейм"
   ```

   Ник должен точно соответствовать заявке. Команда выдаст ID и случайный секретный код **один раз**. Администратор передаёт их пользователю лично, например в ответ через Newgrounds. Не публикуйте код. Никакие письма автоматически не отправляются.
4. Пользователь входит с ID и кодом; ник изменить нельзя. Удаление аккаунта требует повторного ввода кода. Без входа создание объявления недоступно.

Аккаунты хранятся в `data/accounts.json` на том компьютере, где работает сервер; в Git этот файл не попадает. Код хранится только в виде хеша. Администратору нужно делать защищённые резервные копии данных. При перезапуске сервера активные сессии завершаются. Локальный сервер каждого пользователя не разделяет аккаунты с другими: для общего доступа нужен один развёрнутый сервер с постоянным хранилищем. Для HTTPS установите `COOKIE_SECURE=true`. Не выкладывайте папку `data` в открытый доступ. Эта простая реализация предназначена для тестирования, перед публичным запуском необходимы аудит безопасности, защищённое развёртывание, резервирование и более надёжное хранилище/ограничение запросов.

## Ограничения прототипа

Объявления и избранное хранятся только в браузере, примеры объявлений вымышлены. Удаление аккаунта не удаляет локальные черновики. Общего каталога, отправки заявок в inbox, автоматической проверки вайтлиста, оплаты и сообщений на сайте пока нет. Не сообщайте Newgrounds-пароль или код GDS в заявке.
