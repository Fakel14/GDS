# GDS — Geometry Dash Songs

Демонстрационный маркетплейс музыки, ремиксов и скаутинга для сообщества Geometry Dash.

## Запуск

```bash
npm install
npm run dev
```

## Текущее состояние

Каталог, поиск, фильтры, избранное, черновики объявлений и форма заявки работают в браузере. Черновики, избранное и заявка хранятся в localStorage текущего устройства и не видны другим пользователям. Примеры объявлений вымышлены. Аккаунты, сервер, отправка заявок администратору, проверка вайтлиста Newgrounds, сообщения и оплата не подключены. Для реального запуска необходимы сервер, база данных, административная модерация и безопасная платёжная интеграция; не следует считать сохранённую заявку подтверждённой верификацией.
